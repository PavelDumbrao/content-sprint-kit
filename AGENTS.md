# AGENTS.md — инструкция для ИИ-агента участника спринта

Человек участвует в спринте клуба Хардкодинг PRO: месяц ведём соцсети через ИИ. Твоя задача — подготовить его компьютер и аккаунты и довести до первого опубликованного ролика. Он может не быть программистом.

## Правила
1. Веди **по одному шагу**, простыми словами, один вопрос за раз. Не выполняй весь файл разом. После шага коротко скажи, что сделано и что дальше.
2. Всё делай сам. Человека проси только о том, что может сделать только он: регистрация, оплата, вставка ключа, вход в соцсеть, согласие.
3. Перед каждой платной операцией назови, что запускаешь и сколько это стоит, и жди «ок».
4. Ключи сервисов живут только в файле ключей (`.env` в корне этого набора) и в настройках MCP. Человек вписывает их сам. В чат ключи не проси, в ответах не повторяй, в командной строке не передавай.
   Два исключения, так устроен спринт: промпт подключения курса из профиля платформы уже содержит личный ключ и рассчитан на отправку своему агенту; ключ Apify человек отправляет организатору спринта в личные сообщения.
5. Публикуй только после явного «да» человека на показанный предпросмотр.
6. Фото и видео человека отправляй во внешние сервисы только после его «да»: назови сервис и скажи, что файл туда уйдёт.
7. Всё, что ставится глобально, сначала покажи командой и ставь после «да».
8. Все команды запускай из корня этого набора. На Windows вместо `python3` используй `py -3` или `python`.
9. Упёрся — найди решение в справочнике курса (`search_wiki`), потом в документации сервиса. Не приноси голую ошибку.

## Шаг 0. Журнал
Скопируй `STATUS.template.md` в `STATUS.md` и отмечай в нём сделанные шаги. Если `STATUS.md` уже есть, прочитай его и продолжай с первого неотмеченного шага. После перезапуска тебя это единственная память о том, где вы остановились.

## Шаг 1. Компьютер
Запусти `python3 scripts/check_env.py`. Чего нет или устарело — предложи команду и поставь после «да».

| Программа | macOS | Windows |
|---|---|---|
| Python 3.10+ | `brew install python` | `winget install Python.Python.3.12` |
| Node 22+ | `brew install node` | `winget install OpenJS.NodeJS.LTS` |
| git | `brew install git` | `winget install Git.Git` |
| ffmpeg | `brew install ffmpeg` | `winget install Gyan.FFmpeg` |

Нет `brew` на macOS — сначала поставь Homebrew с brew.sh (после «да»). На Linux — `apt`.
Затем библиотеки Python: создай окружение `python3 -m venv .venv`, включи его (macOS и Linux: `. .venv/bin/activate`; Windows: `.venv\Scripts\activate`) и выполни `python -m pip install -r requirements.txt`. Окружение включай в каждом новом окне терминала.

## Шаг 2. Два сервера клуба
Нужны оба: курс (`hardcoding-pro`) и контент-хаб (`content-hub`). Адреса и образцы настроек — `docs/mcp.md`. Добавляй серверы в общие настройки агента для пользователя, а не в файл внутри папки проекта.
1. Проверь курс вызовом `whoami`. Не подключён: попроси человека открыть профиль на платформе, раздел «Ключ для твоего агента», нажать «Скопировать» в блоке «Промпт для агента: подключить курс» и отправить этот промпт тебе. Выполни его.
2. Сразу добавь второй сервер `content-hub`: вместо ключа поставь слово `KEY`, открой файл настроек человеку и скажи, в какой строке заменить `KEY` на ключ из профиля.
3. Отметь шаг в `STATUS.md` и попроси человека один раз полностью перезапустить тебя: серверы читаются при запуске.
4. После перезапуска проверь настоящими вызовами: `whoami` (имя и тариф) и `hub_status`.

Если тариф не PRO: скажи человеку, что спринт и Мастерская открыты с тарифом PRO, и остановись на этом.
Если хаб отвечает, что открыт участникам спринта: человек ещё не внесён в список, пусть напишет организатору.

## Шаг 3. Скиллы и наборы
1. Движок видео кодом: `npm i -g hyperframes`, затем `npx skills add heygen-com/hyperframes`.
2. Наборы клуба: `python3 scripts/get_kits.py`. Если человек хочет ролики с собой в кадре — `python3 scripts/get_kits.py --all`.
3. Из `kits/viral-reel-remake-kit/AGENTS.md` выполни только пункт 1 раздела «Шаг 0. Установка»: скопируй скилл к себе. Остальное там уже сделано здесь: программы, библиотеки, движок, файл ключей.
4. По желанию: `npx skills add remotion-dev/skills` (длинные ролики и уроки), `npx skills add elevenlabs/skills`, студия OpenMotion (https://github.com/nexu-io/openmotion).
5. Посмотри, что есть готового на платформе: `list_workshop`, затем `get_workshop` с параметром `shelf` равным `video`.

## Шаг 4. Сервисы и ключи
Пройди с человеком по `docs/services.md` сверху вниз: сначала обязательные, потом те, что нужны под его формат роликов. На каждый сервис: зачем он, ссылка, что нажать, сколько положить.
- Файл ключей один: скопируй `.env.example` в `.env` в корне этого набора. Человек вписывает ключи сам, по строке на ключ, без пробелов вокруг знака равенства и без кавычек.
- Скрипты наборов читают ключи из окружения. Перед запуском загрузи файл ключей в окружение, не печатая значения (macOS и Linux: `set -a; . ./.env; set +a`).
- Проверка ключей — таблица в `docs/services.md`, раздел «Как проверить ключ».
- Ключ Apify человек отправляет организатору спринта в личные сообщения. Тебе он не нужен.

## Шаг 5. Проверка готовности
Запусти `python3 scripts/check_env.py`, вызови `whoami`, `hub_status`, `list_workshop`. Покажи человеку короткую таблицу: что готово, чего не хватает и что с этим делать.

## Шаг 6. Первая неделя спринта
Веди по `docs/week1.md`: правила хаба и профиль ниши → соцсети → первый поиск → разбор 20 роликов → первый ролик → публикация → цифры.
Ролик собирай по скиллу `viral-reel-remake`. Первый ролик делай без живого аватара: только графика или нарисованный персонаж. Если ключа для картинок ещё нет, делай только графику.

Платные генерации:
- **Картинки:** `python3 scripts/nano_banana.py run <имя> <файл с заданием> --aspect 9:16 --size 2K --image <фото> --out-dir work/img`. Фото уходит провайдеру Grsai.
- **Говорящий клип из фото, проще всего:** набор `omni-video-kit` (Yiciyuang, 720p), он принимает файл с компьютера.
- **Говорящий клип 1080p:** `python3 scripts/omni_clips.py <spec.json> --dry-run`, назови цену, после «ок» — без `--dry-run`. SCAPI принимает фото только по публичной ссылке. Получи отдельное «да» на то, что кадр будет выложен по ссылке; выложи его так же, как это делает `kits/omni-video-kit/scripts/omni.py`. Образец задания — `docs/omni_spec.example.json`.

Чтобы не заплатить дважды:
- `<имя>` задачи уникально. Скрипты ведут журнал и не отправляют одно имя повторно.
- После сбоя или неясного ответа при отправке **не отправляй заново**. Картинки: `python3 scripts/nano_banana.py poll <имя> --out-dir work/img`. Клипы: `python3 scripts/omni_clips.py <spec.json> --poll-only`.
- Ключ `--force` и новая отправка под другим именем — только по слову человека, после проверки баланса в кабинете сервиса.
- Деньги резервируются при отправке. Если сервис не вернул результат, проверь в кабинете, вернулись ли они.

## Шаг 7. После первой недели
Спроси, что было неудобно, и допиши правила в `STATUS.md` и в свой скилл. Дальше темп спринта: 3–5 роликов в день и разбор цифр раз в неделю (`my_stats`).
