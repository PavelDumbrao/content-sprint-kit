# Два сервера клуба

Агент подключает два MCP-сервера. Оба узнают вас по одному личному ключу из профиля платформы.

| Сервер | Имя | Адрес | Что даёт |
|---|---|---|---|
| Курс | `hardcoding-pro` | `https://hardcoding.proaicommunity.online/learn/mcp/` | уроки и сдача, справочник (`search_wiki`, `get_note`), Мастерская (`list_workshop`, `get_workshop`) |
| Контент-хаб | `content-hub` | `https://mcp.proaicommunity.online/hub/mcp` | ниша, поиск роликов, разбор, идеи, публикация, статистика |

Заголовок у обоих один: `Authorization: Bearer <личный ключ>`.

Серверы добавляются в общие настройки агента для пользователя, а не в файл внутри папки проекта: так ключ не попадёт в репозиторий, и серверы видны из любой папки.

## Курс
Самый простой путь: профиль на платформе → «Ключ для твоего агента» → блок «Промпт для агента: подключить курс» → «Скопировать» → отправить агенту. Агент сам найдёт свои настройки и добавит сервер. В этом промпте уже есть ваш личный ключ: платформа рассчитывает, что вы отправите его только своему агенту. В общий чат, на скриншоты и другим людям он попадать не должен.

## Контент-хаб
Агент добавляет второй сервер рядом с курсом и ставит вместо ключа слово `KEY`. Вы заменяете `KEY` на ключ из профиля сами.

Codex, Z-Code и похожие (файл настроек в формате TOML):
```toml
[mcp_servers.content-hub]
url = "https://mcp.proaicommunity.online/hub/mcp"
http_headers = { Authorization = "Bearer KEY" }
```

Агенты с настройками в JSON:
```json
"content-hub": {
  "type": "http",
  "url": "https://mcp.proaicommunity.online/hub/mcp",
  "headers": { "Authorization": "Bearer KEY" }
}
```

Приложение Claude: Customize → Connectors → Add custom connector. Адрес сервера как выше, Authentication: No sign in, заголовок `authorization` со значением из профиля (строка начинается со слова Bearer).

## После подключения
1. Добавьте оба сервера, затем один раз полностью закройте агента и откройте заново: серверы читаются при запуске.
2. Проверка курса: `whoami` — агент называет ваше имя и тариф.
3. Проверка хаба: `hub_status` — агент говорит, что подключено и чего не хватает.

Статус «подключено» в настройках ничего не доказывает: проверяйте только настоящим вызовом инструмента.

## Если не получилось
- Агент не видит инструменты: не перезапущен или сервер добавлен только для одной папки. Подробно — заметка справочника `podklyuchit-agenta-k-kursu`.
- Хаб отвечает, что доступа нет: хаб открыт участникам спринта, напишите организатору.
- Ключ попал в чат или на скриншот: в профиле нажмите «Перевыпустить» и подключите заново.
