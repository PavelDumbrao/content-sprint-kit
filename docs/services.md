# Сервисы и провайдеры спринта

Наш рабочий набор на ноябрь 2026: этим собраны девять эталонных роликов клуба. Цены и условия меняются, перед оплатой сверяйтесь с сайтом сервиса. Китайские провайдеры считают в юанях; рубли ниже пересчитаны примерно по 12 ₽ за юань. Суммы «на старт» — ориентир на первую неделю, а не обязательный платёж.

Как оплатить зарубежный сервис из России — в уроках этапа 0.Б курса; агент найдёт заметку через `search_wiki("оплата")`.

## Обязательно

| Сервис | Зачем | Сколько | Что сделать |
|---|---|---|---|
| Платформа обучения | Личный ключ: по нему вас узнают курс и контент-хаб. С тарифом PRO открыта и Мастерская | уже есть | Войти через Telegram, взять личный ключ в профиле |
| Взнос участника спринта | Общий котёл: поиск роликов, разбор, публикация, сервер | по условиям спринта | Тема «Спринты клуба» |
| Apify | Ваш бесплатный ключ пополняет общий пул, через который хаб ищет залетевшие ролики в Instagram | бесплатно: сервис даёт 5 долларов в месяц на аккаунт | Создать ключ и отправить организатору спринта в личные сообщения. Агенту и в общий чат не отправлять, в файл ключей не вписывать |
| ElevenLabs | Свой клон голоса, озвучка, расшифровка речи по словам | тариф Starter, около 6 долларов в месяц | Сделать клон голоса из 1–2 минут записи, ключ и ID голоса вписать в файл ключей |

## Под ваш формат роликов

| Формат | Сервис | Зачем | Сколько | На старт |
|---|---|---|---|---|
| Любой | HyperFrames, OpenMotion | Графика, сцены, субтитры кодом | бесплатно | — |
| Нарисованный персонаж, кадр образа, перебивки | Nano Banana 2.1 через Grsai | Картинки | меньше 1 ₽ за картинку | 300–500 ₽ |
| Живой человек в кадре, 1080p | Omni 1.2 через SCAPI | Говорящий клип из фото | 0,2 юаня за секунду, около 2,5 ₽ | 1000–2000 ₽ |
| Живой человек в кадре, дешевле, 720p | Omni через Yiciyuang | Говорящий клип из фото | 0,75 юаня за 10 секунд, около 9 ₽ | 500–1000 ₽ |
| Любой с аватаром | ElevenLabs speech-to-speech | Перевести голос клипа в свой | из тарифа Starter | — |
| Уроки и длинные ролики | Remotion, облако Modal или Hugging Face | Сборка и рендер | бесплатный лимит | — |

SCAPI принимает фото только по публичной ссылке, Yiciyuang (набор `omni-video-kit`) — файл с компьютера. Начинать проще с Yiciyuang.

Ориентир по ролику: только графика — 0–30 ₽; нарисованный персонаж — 15–100 ₽; живой аватар 45–90 секунд — 120–300 ₽.

Ориентир на месяц — 6–8 тысяч ₽ при 100+ роликах. Он рассчитан на смесь форматов: в основном графика и нарисованный персонаж, живой аватар в каждом пятом ролике. Сто роликов только с живым аватаром обойдутся в 12–30 тысяч ₽.

Деньги резервируются в момент отправки задания. Если сервис не вернул результат, он обычно возвращает их сам: проверьте баланс в кабинете. Фото, по которому делается картинка или клип, уходит провайдеру.

## Что уже оплачено общим взносом (свои ключи не нужны)

Это делает контент-хаб клуба, агент вызывает его инструменты:
- поиск залетевших роликов в Instagram (общий пул ключей Apify, в который каждый участник даёт свой бесплатный ключ);
- разбор ролика по секундам и идеи с раскадровкой;
- публикация в YouTube, Instagram и TikTok (Post for Me) и в VK, Telegram, Rutube, ОК, Max (Postmypost);
- статистика по вашим публикациям.

У хаба есть суточные лимиты на участника: примерно один поиск и до пяти разборов в день. Упёрлись в лимит — продолжайте завтра.

## Как проверить ключ

| Сервис | Проверка | Стоит |
|---|---|---|
| ElevenLabs | запрос сведений об аккаунте (`GET /v1/user`) | бесплатно |
| Yiciyuang | `python3 scripts/omni.py check` в папке набора `omni-video-kit` | бесплатно |
| Grsai | бесплатной проверки ключа нет: первая картинка | меньше 1 ₽, после «ок» |
| SCAPI | бесплатной проверки нет: `--dry-run` показывает только цену, ключ проверяется первым клипом | после «ок» |
| Gemini API | запрос списка моделей | бесплатно |
| YouTube Data API | `python3 scripts/youtube_niche.py check` | бесплатно, 1 единица квоты |

## Файл ключей

Образец лежит в корне репозитория (`.env.example`), рабочий файл называется так же без `.example`.

| Строка | Для чего |
|---|---|
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | голос, обязательно |
| `GRSAI_API_KEY` | картинки |
| `SCAPI_KEY` | говорящие клипы 1080p |
| `YICIYUANG_API_KEY` | говорящие клипы 720p |
| `GEMINI_API_KEY` | проверка ролика |
| `YOUTUBE_API_KEY` | срез ниши на YouTube |

Ключи вписываете сами. В чат агенту и в общий чат их не отправляйте. Рабочий файл ключей в репозиторий не попадает.
