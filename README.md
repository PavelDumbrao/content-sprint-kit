# content-sprint-kit — весь стек спринта одной фразой агенту

Спринт клуба Хардкодинг PRO: месяц ведём соцсети через ИИ. Находим залетевшие ролики в своей нише, делаем свои, выкладываем во все соцсети и считаем цифры. Этот репозиторий готовит вашего ИИ-агента: он сам ставит программы и скиллы, подключает серверы клуба и ведёт вас до первого опубликованного ролика.

## Как начать (1 минута)
Вставьте своему агенту — Claude Code, Codex, ZCode, Antigravity, Kimi Code, Qwen Code, OpenCode, Cursor или любому другому:

```
Склонируй репозиторий https://github.com/PavelDumbrao/content-sprint-kit, прочитай AGENTS.md и подготовь меня к спринту: поставь всё сам и веди меня по одному шагу.
```

Нет git или агент не смог склонировать: скачайте архив (зелёная кнопка Code → Download ZIP на странице репозитория), распакуйте и скажите агенту открыть эту папку и вести вас по AGENTS.md.

## Что агент сделает сам
- Проверит и поставит программы: Python, Node, git, ffmpeg, yt-dlp.
- Подключит два сервера клуба: курс (уроки, справочник, Мастерская) и контент-хаб (поиск роликов, идеи, публикация, статистика).
- Поставит движок видео кодом и скиллы, скачает наборы клуба.
- Проверит ключи и скажет, чего не хватает.
- Проведёт по первой неделе: ниша, соцсети, поиск, разбор 20 роликов, первый ролик, публикация.

## Что сделаете вы
- Зарегистрируетесь в сервисах и пополните их: список и суммы в [docs/services.md](docs/services.md).
- Вставите ключи в файл настроек. В чат агенту ключи не отправляйте.
- Подключите соцсети по ссылкам от агента.
- Скажете «да» перед каждой публикацией и каждым платным шагом.

## Что нужно заранее
- Вход на платформу обучения и личный ключ из профиля. С тарифом PRO агенту открыта ещё и Мастерская с готовыми решениями.
- Взнос участника спринта (условия — в теме «Спринты клуба»).
- Бюджет на генерацию роликов: ориентир 6–8 тысяч ₽ на месяц при 100+ роликах, если в основном графика и нарисованный персонаж. Эти деньги лежат на ваших ключах.

## Что внутри
```
AGENTS.md                 инструкция агенту: по шагам от пустого компьютера до первой недели
CLAUDE.md, GEMINI.md      вход для агентов, которые читают эти файлы сами
requirements.txt          библиотеки Python для наборов
docs/services.md          сервисы и провайдеры: зачем, сколько положить, что обязательно
docs/mcp.md               как подключить серверы курса и клуба
docs/week1.md             первая неделя спринта по дням
docs/crosspost.md         кросс-постинг: один ролик на все площадки, правила площадок
docs/omni_spec.example.json  пример задания на говорящий клип
scripts/check_env.py      проверка готовности компьютера и ключей
scripts/get_kits.py       скачать наборы клуба
scripts/nano_banana.py    картинки: кадр образа, перебивки, персонаж (Nano Banana через Grsai)
scripts/omni_clips.py     говорящие клипы из фото (Omni через SCAPI)
.env.example              образец файла ключей
STATUS.template.md        журнал шагов, чтобы продолжать после перерыва
```
